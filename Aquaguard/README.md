Project Title: AquaGuard-Water Quality Analytics & Decision Support System

Project Description:

The AquaGuard –Water Quality Analytics & Decision Support System is a Python-based desktop application that analyzes water quality data from different regions. It cleans and processes the data, stores it in a MySQL database, and displays interactive dashboards with charts and reports. The system uses Machine Learning to group water samples based on quality and detect abnormal pollution levels, helping users understand water conditions and support environmental decision-making.
